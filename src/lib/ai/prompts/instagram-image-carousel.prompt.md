# Carousel image prompt guidelines (1024×1024 × 5 · gpt-image-1)

Generate exactly 5 `carouselImagePrompts` — each a **single dense English prompt** for gpt-image-1.

Each slide must:
- Match `carouselSlides[i]` narrative (hook → problem → insight → solution → CTA)
- Share cohesive series color grading and lighting with other slides
- Use cinematic premium tech aesthetic, ultra detail, minimal text
- Include slide number context (1 of 5 … 5 of 5)
- Azure-inspired blues/cyans, futuristic enterprise mood, no logos

Avoid: infographic template look, stock photos, blurry, cluttered UI, typography.
